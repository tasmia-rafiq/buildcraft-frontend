# BuildCraft Landing Page

## Project Setup & Installation
**Clone the repo:**

```
git clone https://github.com/tasmia-rafiq/buildcraft-frontend-task.git
```

**Move into folder:**
```
cd buildcraft-frontend
```

**Install packages:**
```
npm install
```

## Running the Project

**Start development server:**
```
npm run dev
```

- Open http://localhost:3000 in your browser
